# AI Usage in Monyx Development

## Overview
This document outlines the AI tools and models used during the development of Monyx, focusing on coding assistance and prototype development. As a developer with a graphic design background, I relied on the natve AI tools present in Canva for design tasks, while using GitHub copilot for coding and prototyping.

## AI Tools for Coding via GitHub Copilot
- **Claude Sonnet 4**: Utilized for generating code snippets, debugging assistance, and brainstorming implementation ideas. Helped in structuring backend logic and frontend components efficiently.
- **Grok Code Fast 1**: Integrated into the development environment for real-time code suggestions, autocompletions, and quick fixes. Assisted in writing React components, API integrations, and overall code quality improvements.

## Prototype Development
The same AI tools (Claude Sonnet 4 and Grok Code Fast 1 via GitHub Copilot) were instrumental in rapid prototyping. They aided in:
- Scaffolding initial project structures.
- Generating boilerplate code for features like OCR, analytics, and transaction management.
- Iterating on UI/UX ideas through code-based prototyping.

## Design Tool Usage
Due to my graphic design background, AI design tools were not heavily relied upon. I used Canva and its native AI support for creating visual assets, and [Hover.dev](https://www.hover.dev) for React components.
 No significant AI design tool credits were consumed in this project.

## Acknowledgement
AI played a supportive role in accelerating development and enhancing productivity, but the core design and architectural decisions were driven by human expertise and creativity.
